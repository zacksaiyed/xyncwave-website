# Making complex healthcare data consistent before it reaches downstream workflows.

A healthcare data-processing environment combining rule-based transformation, distributed processing, orchestration, staging and validation around complex billing and operational data.

## Context

A pipeline built around the realities of healthcare source data.

- **Business environment:** Healthcare data and billing operations
- **Data scope:** Patient, account, facility, service and billing-related information
- **Processing model:** Multi-stage transformation and validation pipelines
- **Technology environment:** EasyMorph, Databricks, Azure Data Factory, PySpark and SQL Server

## Raw healthcare data rarely arrives ready for downstream use.

Source files contained different identifiers, classifications, formatting patterns and business rules. Processing also needed to remain traceable when records were filtered, omitted or transformed unexpectedly.

## A layered pipeline for transformation, validation and reliable processing.

Rule-based transformation, distributed processing and orchestrated staging were combined so each stage had a clear responsibility and records could be investigated when results looked wrong.
